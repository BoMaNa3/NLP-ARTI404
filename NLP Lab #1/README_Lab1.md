# Lab 1: Introduction to Natural Language Processing

## Overview

In this lab, I explored the foundations of Natural Language Processing (NLP). I learned how NLP connects linguistics, computer science, machine learning, and deep learning to help computers process and analyze human language.

I also reviewed why language is difficult for computers to understand, including ambiguity, spelling errors, similar pronunciations, and the effect of word order on meaning.

## What I Covered

- The meaning and purpose of NLP
- The main resources behind modern NLP: data, computing power, and algorithms
- Challenges such as ambiguity, spelling errors, phonetics, and context
- Common text formats used in NLP, including CSV, TXT, JSON, HTML, PDF, and DOCX
- Popular NLP applications:
  - Information extraction
  - Machine translation
  - Sentiment analysis
- The basic stages of an NLP pipeline
- An introduction to the Natural Language Toolkit (NLTK)
- A brief overview of Arabic NLP libraries such as CAMeL Tools, PyArabic, and Farasa
